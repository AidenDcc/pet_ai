
# ShuxinPet 宠物智能后台管理系统 UI 风格AI生成提示词文档
## 文档概述
本文档基于ShuxinPet宠物健康监测后台控制台页面拆解视觉规范、配色体系、页面布局、分模块AI绘图提示词、后台数据表设计规则，可直接复制用于Midjourney、Stable Diffusion、AI UI生成工具、产品原型描述。

---

## 一、全局完整版AI提示词（直接复制使用）
### 1.1 正向提示词 Positive Prompt

B 端宠物智能穿戴设备后台管理控制台网页，1920 分辨率 PC 桌面端，经典左右分栏中后台布局；
左侧固定浅米白色 #F9FCF7 竖向折叠导航菜单栏，线性简约图标 + 文字分组菜单，选中菜单项淡薄荷绿圆角高亮；
顶部通栏纯白色全局导航条，左上角 ShuxinPet 系统 Logo，右上角页面导航菜单 + root 用户头像下拉操作入口；
右侧主内容区全部采用统一 8px 圆角白色卡片模块化排版，仅添加极浅卡片悬浮阴影，无厚重立体效果；
核心主题配色：低饱和薄荷绿 #72D1A8 为主色、深森林墨绿 #0F4736 为深色卡片背景、浅青绿 #B3E8CC 做分割装饰线；
页面模块自上而下依次：

1. 浅绿渐变欢迎信息横幅大卡片，左侧欢迎文案 + 角色标签，右上角悬浮账号状态信息面板；
2. 一行三等分 3 个白色数据概览卡片，每张卡片顶部搭配一条细青绿色横向装饰条，内部为标题、备注说明、右侧状态小图标；
3. 宠物健康总览深色数据大屏模块，深墨绿色全屏圆角卡片，左侧展示设备型号、宠物信息、心率 / 呼吸 / 血氧三项体征数据嵌入式方框，右侧竖向健康得分绿色进度条、设备在线状态、电量、最后同步时间列表；
配套数据表格采用大气简洁商务风格：细单线浅灰色边框，表头填充浅薄荷绿底色，鼠标悬停行浅灰色高亮，单元格留白充足，极简底部分页控件；
整体视觉：极简扁平风、大量留白、Inter 纤细无衬线字体、层级清晰、3C 智能硬件运维后台专业质感，干净通透、高可读性，无多余花哨装饰。

### 1.2 反向规避提示词 Negative Prompt

3D 渲染，拟物化设计，厚重阴影，高饱和刺眼荧光绿，杂乱光斑，卡通插画，移动端竖版布局，老旧臃肿后台界面，多重浮雕粗边框，过度渐变特效，弹窗遮挡主体，杂乱装饰元素，立体凸起按钮

## 二、分模块独立精准提示词
### 2.1 左侧侧边导航栏


B 端后台左侧固定竖向侧边菜单栏，底色 #F9FCF7 浅米白色，菜单分为工作台、账户两大分组；一级菜单搭配简约线性图标 + 中文文字，选中条目使用淡薄荷绿小圆角背景高亮，次要文字为深灰色细体；支持折叠仅展示图标模式，窄栏悬浮固定，极简清爽，匹配 ShuxinPet 绿色主题体系。


### 2.2 顶部全局导航栏


后台系统顶部通栏纯白色导航条，左上角放置 ShuxinPet 英文 Logo，中间区域留白，右上角横向排列文字导航：首页、产品、健康监测、安全定位、Blog、关于我们，最右侧功能图标按钮 + root 管理员用户头像下拉按钮；hover 仅文字变色，无下划线、无背景高亮，极致简约扁平风格。

### 2.3 首页顶部欢迎横幅卡片


大圆角白色背景横幅卡片，左侧内嵌浅薄荷绿柔和渐变区域，大号加粗字体展示欢迎文案，下方小字功能描述，底部附带角色、登录状态、工作台标签按钮；卡片右上角悬浮独立白色圆角面板，展示当前账号名称、绑定邮箱状态、账号角色、安全登录状态，整体柔和轻量化，无冗余元素。


### 2.4 三栏数据统计卡片组


一行均等划分 3 个白色圆角数据卡片，卡片顶部统一添加一条细青绿色横向分割装饰线；卡片内部左侧为模块标题 + 小号辅助说明文字，右侧搭配圆形简约状态图标；三个模块分别为账号权限、会话状态、快捷入口，间距均匀对称，标准商务后台数据看板样式。


### 2.5 宠物健康深色核心数据大屏


深森林墨绿色 #0F4736 超大圆角数据卡片，左侧区域展示设备编号、宠物品类名称、功能描述文案，下方三个内嵌深色矩形数据框分别承载心率 bpm、呼吸 rpm、血氧百分比数值；右侧白色独立板块为今日健康摘要，大号百分比数字 + 长款绿色进度条，下方分行罗列设备在线状态、剩余电量、最后数据同步时间；高对比度白色文字，智能生命体征监测科技面板，极简数据可视化。

### 2.6 配套大气简洁数据表专项提示词


适配 ShuxinPet 绿色主题后台的数据表格组件，大气极简商务规范：

1. 外层容器：极细浅灰色单线边框、8px 圆角包裹整个表格；
2. 表头行：背景色 #E6F7EF 浅薄荷绿，表头文字加粗深灰色，单元格统一左对齐；
3. 表格内容行：纯白底色，无隔行变色，鼠标 Hover 单行填充淡浅灰色底色高亮；
4. 单元格：上下左右预留充足内边距，状态标识使用小色块标签（在线绿色、离线灰色）；
5. 底部：极简数字分页器，仅保留上一页、下一页箭头与页码；
6. 表格顶部可搭配搜索筛选栏、新增、导出功能按钮，按钮填充主题薄荷绿圆角样式；
适用于设备列表、宠物档案、围栏告警、服务账单全后台列表页面。
