# 1. 引言

## 1.1 目的

本文档定义数心智能宠物健康平台（ShuxinPet）**平台运营端（管理后台）**的完整产品需求，明确功能范围、业务规则、交互逻辑与数据要求，作为研发、UI 设计、测试与运营验收的统一依据。文档以「分模块、分页面、分用户角色」的粒度描述需求，可直接拆解为开发任务与测试用例。

# 2. 总体描述

## 2.1 产品视角

ShuxinPet 平台运营端是面向平台运营人员的中后台管理控制台，负责平台的经营监控与业务治理，覆盖设备、用户、宠物、医生、订单、订阅等核心业务对象的管理，以及系统级配置（用户 / 角色 / 菜单 / 字典 / 日志 / 终端 / 国际化）。

运营端采用桌面中后台经典左右分栏布局：左侧固定浅米白 `#F9FCF7` 竖向折叠导航菜单，顶部通栏白色导航条，右侧主内容区统一 8px 圆角白色卡片模块化排版。主题色采用低饱和薄荷绿 `#72D1A8` 为主色、深森林墨绿 `#0F4736` 为深色卡片背景、浅青绿 `#B3E8CC` 做分割装饰线，整体极简扁平、大量留白、高可读性。

## 2.2 产品功能概述

平台运营端功能按模块划分如下：

| 模块 | 主要页面 | 核心能力 |
| ---- | ---- | ---- |
| 账号与登录 | 登录、注册、找回密码 | 管理员登录、账号注册、密码重置 |
| 整体框架 | 侧边栏、顶栏 | 菜单分组、折叠、语言切换、账号面板 |
| 数据看板 | 看板 | 欢迎横幅、6 统计卡片、4 图表、业务总览 |
| BI 报表 | 运营监控、设备报表、宠物监控、宠物医院 | 多维度 KPI 与图表分析 |
| 设备管理 | 设备主档案、固件包管理、激活设备管理 | 设备主数据、固件上传、激活设备监控 |
| 用户管理 | C 端用户 | 用户列表与详情、状态管理 |
| 宠物管理 | 宠物档案、健康管理、健康报告、报告详情 | 宠物档案、健康看板、报告生成与查看 |
| 医生管理 | 医生列表 | 医生列表与认证审核 |
| 订单管理 | 订单列表 | 订单筛选与状态管理 |
| 订阅管理 | 套餐管理 | 套餐价格调整与订阅人数 |
| 系统管理 | 系统用户 / 角色 / 菜单 / 字典 / 日志 / 终端 / 国际化 | RBAC 权限、字典、日志、终端、词条管理 |

## 2.3 用户特征

| 用户角色 | 特征 | 使用场景 |
| ---- | ---- | ---- |
| 平台管理员 | 拥有全部权限，负责系统级配置与全局治理 | 系统用户 / 角色 / 菜单 / 字典 / 终端 / 词条管理 |
| 运营人员 | 关注经营数据与业务治理 | 数据看板、BI 报表、设备 / 用户 / 宠物 / 医生 / 订单 / 订阅管理 |
| 审核人员 | 负责医生资质、报告等审核 | 医生认证审核、报告查看 |

用户特征假设：运营人员以桌面端为主，操作以「查询、筛选、导出、审核」为主；对经营指标与异常数据敏感，需要看板与报表；权限按 RBAC 角色控制，不同角色可见菜单与操作不同。

## 2.4 运行环境

| 项目 | 说明 |
| ---- | ---- |
| 呈现形态 | 桌面中后台（PC 端，1920 分辨率基准） |
| 目标浏览器 | Chrome / Safari / Edge 最新两个大版本 |
| 前端技术栈 | Vue 3.5 + TypeScript + Vite + Element Plus + Pinia + vue-i18n |
| 图表能力 | ECharts 5（收入趋势、设备状态、套餐分布、地图等） |

## 2.5 约束与假设

**约束：**

1. 运营端数据来源于平台后端，当前以 mock 层模拟；价格调整、认证审核等变更即时生效于内存数据。
2. 系统管理涉及 RBAC 权限，需保证角色 — 菜单 — 权限的映射完整。
3. I18N 词条在线编辑后运行时生效，需保证中英文 key 对齐。

**假设：**

1. 平台管理员默认拥有全部菜单与操作权限。
2. 设备主档案记录产线 / 在售 / 已售全部设备，激活设备为其中已完成激活的子集。
3. 订阅套餐固定为基础 / 专业 / 尊享三档，价格可在线调整。

# 3. 功能需求

> 功能编号规则：`FR-OPS-XXX`（XXX 为三位递增序号）。每个功能点按「功能描述 / 前置条件 / 操作流程 / 业务规则 / 异常处理」描述。

## 3.1 账号与登录

### 3.1.1 管理员登录（FR-OPS-001）

**功能描述**：平台运营人员通过邮箱账号 + 密码登录管理后台，支持明文切换、回车提交、记住我，展示本端演示账号一键登录。

**前置条件**：已创建运营账号。

**操作流程**：

1. 进入 `/admin/login`，输入邮箱账号 + 密码（可切换明文 / 密文）。
2. 回车或点击提交登录。
3. 登录成功写入登录态，跳转数据看板。

**业务规则**：登录校验账号角色为 admin；勾选「记住我」持久化登录态；演示账号 `admin` / `123456` 一键填充；角色错配提示「该账号不属于当前入口」。

**异常处理**：账号或密码错误提示并保留输入；账号禁用提示联系管理员。

### 3.1.2 运营账号注册（FR-OPS-002）

**功能描述**：运营账号通过手机号 / 邮箱 + 验证码完成注册。

**业务规则**：联系类型 Tab（手机号 / 邮箱）+ 国际区号；验证码 60s 倒计时；密码 6–20 位须含字母与数字。

### 3.1.3 找回密码（FR-OPS-003）

**功能描述**：运营人员通过手机号 / 邮箱 + 验证码（scene=reset）重置密码。

**业务规则**：账号不存在拦截；重置成功后跳转登录。

## 3.2 整体框架

### 3.2.1 侧边栏菜单（FR-OPS-004）

**功能描述**：左侧竖向折叠导航菜单，菜单分为工作台（数据看板、BI 报表 4 项）、业务管理（设备 / 用户 / 宠物 / 医生 / 订单 / 订阅）、系统管理（系统用户 / 角色 / 菜单 / 字典 / 日志 / 终端 / 国际化）三组。

**业务规则**：一级菜单配线性简约图标 + 文字分组；选中条目淡薄荷绿圆角高亮；菜单按 RBAC 权限动态渲染。

### 3.2.2 侧边栏折叠与顶栏（FR-OPS-005）

**功能描述**：侧边栏可折叠（224↔64px）；顶栏展示品牌 Logo + 当前页标题 + 语言切换 + 账号头像下拉（退出登录等）。

**业务规则**：折叠后仅展示图标；语言切换中 / 英；头像下拉提供退出登录入口。

## 3.3 数据看板

### 3.3.1 欢迎横幅与账号面板（FR-OPS-006）

**功能描述**：看板顶部欢迎横幅展示欢迎语 / 角色 / 在线标签；右上角悬浮账号状态面板展示账号名称 / 绑定邮箱 / 角色 / 安全登录状态。

**业务规则**：欢迎语含管理员名称；账号面板展示当前账号信息与登录安全状态。

### 3.3.2 统计卡片（FR-OPS-007）

**功能描述**：一行 6 个数据概览卡片：设备总数 / 在线设备数 / 用户总数 / 在线宠物数 / 待审核兽医数 / 本月新增用户。

**业务规则**：卡片顶部细青绿色装饰条；数值实时反映 mock 数据。

### 3.3.3 ECharts 图表与业务总览（FR-OPS-008）

**功能描述**：4 张图表：营收趋势折线 / 设备状态环形饼图 / 设备激活趋势柱状 / 套餐分布环形饼图；配套业务总览。

**业务规则**：图表数据随时间与业务变更联动；业务总览汇总关键指标。

## 3.4 BI 报表

### 3.4.1 运营监控报表（FR-OPS-009）

**功能描述**：运营监控报表展示 KPI 指标卡（日活 / 总用户 / 总宠物 / 累计激活设备 / 活跃设备 / 兽医数 / 合作医院等）+ 图表与告警：用户趋势（双 Y 轴）、设备趋势（双 Y 轴）、各省激活设备地图、用户留存（7 日 / 15 日 / 1 月 / 3 月 / 半年）、健康指标告警轮播、医院问诊排行。

**业务规则**：KPI 带环比增量；双 Y 轴区分指标量级；地图按省份着色；告警按预警 / 危险分级轮播。

### 3.4.2 设备报表（FR-OPS-010）

**功能描述**：设备报表展示设备总数 / 在线 / 离线 / 本月新增 / 平均使用时长 KPI + 新增设备趋势、在线趋势（双 Y 轴）、异常设备列表。

**业务规则**：异常设备列表展示 SN / 名称 / 宠物名 / 异常类型 / 详情 / 最后同步时间。

### 3.4.3 宠物监控报表（FR-OPS-011）

**功能描述**：宠物监控报表展示本月新增宠物 / 总数 / 已绑定 / 今日异常 KPI + 物种分布饼图、城市宠物 top10、异常趋势、异常指标排行、每日在线宠物平均体征、运动指标趋势、异常宠物列表。

**业务规则**：物种分布猫 / 狗；城市 top10 排行；异常宠物列表按预警 / 危险分级。

### 3.4.4 宠物医院报表（FR-OPS-012）

**功能描述**：宠物医院报表展示医院总数 / 在线医生 / 今日问诊 / 逾期未处理 / 平均响应时长 / 本月新增 KPI + 合作方式分布饼图、各省合作医院数、问诊 / 办结 / 响应时长趋势、点赞优秀医院 top10、点赞优秀医生 top10。

**业务规则**：合作方式分布统计；响应时长趋势展示均值变化。

## 3.5 设备管理

### 3.5.1 设备主档案列表（FR-OPS-013）

**功能描述**：设备主档案列表支持状态下拉筛选 + 关键字搜索（SN / 资产编号 / 产品名 / 型号）；表格展示 SN / 产品名 / 型号 / 品牌 / 分类 / 状态等。

**业务规则**：状态筛选生效 / 失效；关键字模糊匹配多字段；分页展示。

### 3.5.2 新增 / 编辑设备（FR-OPS-014）

**功能描述**：设备主档案新增 / 编辑采用四页签表单：基本信息（图片 / 资产编号 / SN / 产品名 / 品牌 / 型号 / 分类联动 / IMEI）、通讯配置（通讯方式多选 / 各方式 Mac / 协议）、版本信息（硬件版本 / 固件版本）、其他（颜色 / 出厂日期 / 注册日期 / IoT 设备 ID / 令牌 / 支持指标）。

**业务规则**：SN / IMEI 唯一；分类一级 / 二级联动；通讯方式多选；支持指标多选。

**异常处理**：SN 重复提示；必填项校验。

### 3.5.3 设备详情与状态切换（FR-OPS-015）

**功能描述**：设备详情弹窗展示 4 组描述列表；支持失效 / 生效状态切换（二次确认）。

**业务规则**：状态切换需二次确认；详情只读展示主数据。

### 3.5.4 Excel 导入（FR-OPS-016）

**功能描述**：设备主档案支持拖拽上传 .xlsx / .xls + 下载 CSV 导入模板 + 导入（提示条数）。

**业务规则**：支持 .xlsx / .xls；提供 CSV 模板下载；导入后反馈成功 / 失败条数。

**异常处理**：文件格式错误提示；导入数据校验失败逐条提示。

### 3.5.5 固件包管理（FR-OPS-017）

**功能描述**：固件包列表支持状态下拉 + 关键字搜索；表格展示名称 / 版本 / 支持型号 / 支持分类 / 发布日期 / 状态 / 升级设备数。

**业务规则**：状态发布 / 未发布；支持型号多选可自定义。

### 3.5.6 固件包上传 / 编辑 / 查看（FR-OPS-018）

**功能描述**：上传弹窗填写名称 / 版本 / 支持型号多选可自定义 / 分类 / 发布日期 / 发布状态 / 固件文件拖拽上传；编辑与查看对应操作。

**业务规则**：固件文件拖拽上传；发布状态可切换。

### 3.5.7 激活设备管理（FR-OPS-019）

**功能描述**：激活设备列表支持状态筛选 + 关键字搜索；表格展示 SN / IMEI / 状态 / 电量进度条（分色）/ 固件 / 激活时间等。

**业务规则**：电量进度条分色（充足 / 偏低 / 低电量）；展示激活时间与绑定信息。

## 3.6 用户管理

### 3.6.1 C 端用户列表（FR-OPS-020）

**功能描述**：C 端用户列表支持状态筛选 + 关键字搜索（姓名 / 手机号 / ID）；表格展示用户（头像 + 名 + ID）/ 手机号 / 邮箱 / 宠物数 / 订阅套餐 / 注册时间 / 状态。

**业务规则**：状态筛选正常 / 禁用；关键字匹配多字段；分页展示。

### 3.6.2 用户详情与状态管理（FR-OPS-021）

**功能描述**：用户详情查看个人资料、名下宠物、订阅信息；支持启用 / 禁用账号。

**业务规则**：禁用后用户无法登录；操作需二次确认。

## 3.7 宠物管理

### 3.7.1 宠物档案列表（FR-OPS-022）

**功能描述**：宠物档案列表支持物种筛选 + 搜索；表格展示宠物（头像 + 物种图标 + 名 + 品种）/ 物种 / 年龄 / 性别 / 体重 / 主人 / 设备状态。

**业务规则**：物种筛选犬 / 猫；展示主人与设备绑定状态。

### 3.7.2 单宠物健康看板（FR-OPS-023）

**功能描述**：宠物健康管理支持宠物可搜索下拉；宠物信息头（含主人 / 设备状态）；三页签：体征监测（最新体征卡 + 趋势）、运动监测、报告。

**业务规则**：切换宠物刷新看板；体征监测展示最新值与趋势曲线。

### 3.7.3 健康报告列表与生成（FR-OPS-024）

**功能描述**：健康报告列表支持宠物下拉筛选 + 「生成报告」；表格展示宠物 / 主人 / 周期 / 健康分（<85 警告色）/ 评级 / 来源 / 审核状态。

**业务规则**：可手动生成报告；健康分 <85 警告色；展示 AI / 离线来源与医生审核状态。

### 3.7.4 报告详情（FR-OPS-025）

**功能描述**：报告详情页展示健康分环形图 + 概览标签（异常数 / 评级 A/B/C/D / 来源 / 审核状态）、宠物信息、AI 结论、异常项、医生意见。

## 3.8 医生管理

**业务规则**：目录 / 菜单 / 按钮三级类型；层级树形展示；权限标识如 `admin:user:add`。

### 3.11.4 数据字典（FR-OPS-032）

# 4. 非功能需求

## 4.1 性能需求

1. 看板与 BI 报表首屏可交互时间目标 ≤ 3s。
2. 列表分页加载，单页 pageSize 10–20 条，大数据量下虚拟滚动或分页优化。
3. ECharts 图表单图数据点 ≤ 2000，保证渲染流畅。
4. Excel 导入支持批量数据处理，单次导入建议 ≤ 5000 行。

## 4.2 安全性需求

1. 登录鉴权：请求携带 `Authorization: Bearer <token>`，按 token 解析用户并校验角色为 admin。
2. 密码 BCrypt 等不可逆加密存储；手机号等敏感信息加密存储。
3. RBAC 权限：菜单与操作按角色权限动态渲染，无权限操作不可见 / 不可执行。
4. 登录日志记录登录来源（IP / 归属地 / 浏览器 / 系统）与成功 / 失败状态，便于安全审计。

## 4.3 可靠性需求

1. 数据变更（价格调整、认证审核、设备状态切换、系统配置增删改）即时生效并回读校验。
2. 关键操作（失效设备、禁用账号、驳回医生、删除角色 / 菜单 / 字典、清空日志）需二次确认。
3. 网络异常、接口失败提供统一错误提示与重试。

## 4.4 可用性需求

1. 界面遵循极简扁平中后台规范，主题薄荷绿；表格采用浅薄荷绿表头、浅灰单线边框、hover 高亮、8px 圆角。
2. 支持中英双语切换，词条运行时编辑生效。
3. 列表页统一搜索、筛选、刷新、新增、导出（部分）操作区。

## 4.5 兼容性需求

1. 兼容 Chrome / Safari / Edge 最新两个大版本，1920 分辨率基准，支持 1440 及以上分辨率自适应。
2. 侧边栏折叠适配窄屏。

## 4.6 国际化需求

1. 全端中英双语，vue-i18n 管理，词条可在 I18N 模块在线编辑，运行时生效。

# 5. 接口需求

## 5.1 用户接口

1. 统一响应包：`{ code, data, message }`，`code === 0` 成功，响应拦截器自动解包。
2. 统一鉴权：请求拦截器附加 `Authorization: Bearer <token>`。
3. 分页接口统一参数 `{ page, pageSize, keyword?, status? }`，返回 `{ list, total, page, pageSize }`。
4. 模拟延迟 150–500ms。

## 5.2 软件接口

1. ECharts 5：看板与 BI 报表图表（折线 / 饼图 / 柱状 / 地图）。
2. Element Plus：表格、表单、弹窗、树、上传等组件。
3. vue-i18n：词条加载与运行时覆盖。

## 5.3 通信接口

1. 运营端通过平台后端接口管理设备、用户、宠物、医生、订单、订阅等业务对象。
2. 价格调整、认证审核等变更通过接口回写平台数据。
3. Excel 导入通过文件上传接口批量写入设备主档案。

# 7. 其他需求

## 7.1 法律与合规需求

1. 用户个人信息（手机号、邮箱）加密存储，权限内最小化可见。
2. 登录日志记录 IP / 归属地用于安全审计，符合数据合规要求。
3. 医生认证审核需校验职业资质，保障医疗内容合规。

## 7.2 业务规则

1. 角色 — 菜单 — 权限按 RBAC 映射，角色编码唯一。
2. 设备主档案 SN / IMEI 唯一；分类一级 / 二级联动。
3. 健康评分 <85 展示警告色；综合评级 A/B/C/D。
4. 医生认证状态待审核 / 已通过 / 已驳回，通过后方可接诊。
5. 订单状态待支付 / 已支付 / 已退款 / 已过期。

## 7.3 算法与计算需求

1. BI 报表 KPI 环比增量：`deltaPct = (当期 - 上期) / 上期`，周期为周 / 月。
2. 用户留存按 7 日 / 15 日 / 1 月 / 3 月 / 半年口径计算。
3. 设备在线趋势、平均使用时长按日聚合统计。
4. 健康报告综合评级 A/B/C/D 依据《宠物健康数据分析规则体系 v2.1》。
